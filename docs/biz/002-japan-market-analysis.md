# 日本市場分析レポート: 株式3D可視化プラットフォーム

作成日: 2025-02-01

---

## 1. エグゼクティブサマリー

### 日本市場の魅力
- **個人株主数が過去最高を更新中**（8,359万人、11年連続増加）
- **新NISAで若年層が急増**（20代以下の口座開設率が最高）
- **既存の可視化ツールは2D中心**（3D特化プレイヤーは不在）
- **「SNS映え」を重視する若年層**がメインターゲットになり得る

### 結論
日本市場は「3D株式可視化ツール」の参入余地が大きい。
特に20-30代の新NISA利用者をターゲットにしたSNS映えするツールに勝機あり。

## 2. 日本の個人投資家市場

### 個人株主数の推移

| 年度 | 個人株主数（延べ） | 前年比 |
|------|-------------------|--------|
| 2023年 | 7,445万人 | - |

### 証券口座数

## 3. 新NISA効果と若年層の投資トレンド

### NISA口座の急増

| 時点 | 口座数 | 買付額累計 |
|------|--------|-----------|
| 2023年12月末 | 2,125万口座 | - |
| 2024年9月末 | 2,508万口座（+18%） | 13.8兆円 |
| 2025年3月末 | 2,647万口座 | 59兆円 |

### 年代別NISA口座開設率（2024年）

| 年代 | 口座開設率 |
|------|-----------|
| **30代以下** | **83.2%** |
| 40代 | 79.9% |
| 50代 | 75.6% |
| 70代以上 | 63.6% |

### 若年層の投資行動の特徴

```
┌─────────────────────────────────────────────────────┐
│  若年層（20-30代）の特徴                            │
├─────────────────────────────────────────────────────┤
│  ・NISA保有率は30代が最高（約4人に1人）             │
│  ・20代の保有率が50代以上を上回る（逆転現象）       │
│  ・74.7%が「公的年金に期待していない」              │
│  ・SNSや動画サイトから投資情報を得る               │
│  ・インデックスファンドから始める傾向               │
└─────────────────────────────────────────────────────┘
```

### 投資を始めたきっかけ（若年層）

1. **SNSの情報**（最多）
2. 周囲の影響
3. 新NISA制度の開始
4. 将来の年金不安

## 4. 日本の競合分析

### 株式可視化ツール（日本対応）

| ツール | 提供元 | 形式 | 価格 | 特徴 |
|--------|--------|------|------|------|
| **TradingView** | TradingView | 2D | 無料/有料 | グローバル標準、日本株対応 |
| **楽天マーケットスピードII** | 楽天証券 | 2D | 無料（口座必要） | ヒートマップ、リプレイ機能 |
| **SBI証券ヒートマップ** | SBI証券 | 2D | 無料（口座必要） | 日本株・米国株対応 |
| **moomoo** | moomoo証券 | 2D | 無料 | 150万人利用、多市場対応 |
| **カビュウ** | テコテック | 2D | 無料/有料 | ポートフォリオ管理特化 |
| **Stock+** | 個人開発 | 2D | 無料 | シンプルなマップ |

### 競合の特徴まとめ

```
┌─────────────────────────────────────────────────────┐
│  日本市場の競合状況                                 │
├─────────────────────────────────────────────────────┤
│  ✓ 2Dヒートマップは証券会社が無料提供              │
│  ✓ TradingViewが事実上のスタンダード               │
│  ✓ カビュウがポートフォリオ管理で差別化            │
│  ✗ 3D可視化ツールは存在しない                      │
│  ✗ SNS映えを意識したツールは少ない                 │
└─────────────────────────────────────────────────────┘
```

### カビュウの詳細分析（最も近い競合）

| 項目 | 内容 |
|------|------|
| 運営 | 株式会社テコテック |
| 特徴 | 投資管理・分析アプリ |
| 機能 | アモルファス・ヒートマップ、配当金グラフ |
| 対応 | 日本株、米国株 |
| 強み | ポートフォリオの変化を自動記録 |
| 弱み | 2D、市場全体の可視化ではない |

## 7. 日本市場特有の機会

### 1. 新NISA世代へのアプローチ

```
「とりあえずインデックスファンド」の次のステップとして
→ 市場全体を3Dで俯瞰できるツール
→ 個別株への興味喚起
```

### 2. SNS映え需要

```
若年層の投資情報源 = SNS
→ スクリーンショット/動画がシェアされやすいUI
→ TikTok/Instagram/Xでのバイラル狙い
```

### 3. 証券会社との連携

```
日本の証券会社は差別化に苦戦中
→ ユニークな可視化ツールの提供
→ ホワイトラベル/API提供の可能性
```

### 4. 金融教育市場

```
金融リテラシー教育の需要増
→ 学校/企業向け教育ツールとしての展開
→ 「見て学ぶ」株式市場
```

## 8. 懸念事項・リスク（日本市場特有）

### 高リスク

| リスク | 詳細 | 対策案 |
|--------|------|--------|
| **証券会社の無料ツール** | 楽天/SBIが無料でヒートマップ提供 | 3Dという差別化、口座不要の手軽さ |
| **金融商品取引法** | 投資助言に該当する可能性 | 法務確認、免責事項の明記 |
| **日本株データの取得** | 東証データは有料ライセンス必要な場合あり | Yahoo Finance Japan等の利用可否確認 |

### 中リスク

| リスク | 詳細 | 対策案 |
|--------|------|--------|
| **TradingViewの圧倒的シェア** | 日本でも事実上のスタンダード | 「補完ツール」としてのポジショニング |
| **若年層の課金抵抗** | 無料ツールに慣れている | フリーミアム、広告モデル |

### 低リスク

| リスク | 詳細 | 対策案 |
|--------|------|--------|
| **日本語対応** | 当然必要 | 初期から日本語UI |
| **日本株の銘柄数** | 約3,800銘柄（東証） | パフォーマンス検証必要 |

## 9. 追加調査項目（日本市場）

### 優先度: 高

- [ ] **東証データのライセンス確認**: リアルタイム株価表示の法的要件
- [ ] **Yahoo Finance Japan API**: 商用利用可否、制限事項
- [ ] **カビュウのユーザー数・収益モデル**: 競合の詳細分析
- [ ] **投資系インフルエンサー10人へのヒアリング**: ツール需要の確認

### 優先度: 中

- [ ] **楽天/SBI証券のAPI公開状況**: 連携可能性
- [ ] **金融庁への事前相談**: 投資助言該当性の確認
- [ ] **日本の投資アプリのApp Storeレビュー分析**: ユーザーの不満点
- [ ] **TradingView日本ユーザーの不満点**: SNS/コミュニティから収集

### 優先度: 低

- [ ] **金融教育市場の規模**: 学校/企業向け需要
- [ ] **証券会社のマーケティング担当者へのアプローチ**: B2B可能性

## 10. 日本市場向け戦略案

### Phase 1: 日本株特化MVP

```
・東証プライム市場の主要銘柄（225銘柄〜）
・日本語UI
・SNSシェア機能を初期から実装
・無料提供でユーザー獲得
```

### Phase 2: コミュニティ構築

```
・投資系インフルエンサーとのコラボ
・X（Twitter）/TikTokでのバイラル施策
・ユーザー投稿機能（ポートフォリオシェア）
```

### Phase 3: 収益化

```
・プレミアム機能（リアルタイムデータ、アラート）
・証券会社へのホワイトラベル提供
・金融メディアへの埋め込みウィジェット
```
